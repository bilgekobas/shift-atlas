# Contribution Guide

The atlas accepts case suggestions that document climate-responsive architectural, spatial, material, or body-scale strategies.

## Case submission template

### 1. Case identity

- Case title
- Regional variant name, if applicable
- Location
- Coordinates
- Climate zone
- Period
- Typology
- Material
- Scale
- Source category

### 2. Case interpretation

A short paragraph explaining why the case matters as climate-adaptation knowledge.

### 3. Climate pressures

List the main environmental pressures.

Examples:

- Heat stress
- Solar exposure
- Humidity
- Wind exposure
- Cold stress
- Rainfall
- Diurnal variability

### 4. Adaptive logic

Use the atlas hierarchy:

```text
Condition → Mechanism → Strategy Family → Regional Variant → Element
```

### 5. Climate Problem → Response Matrix

| Climate Pressure | Mechanism | Strategy Family | Local Strategy | Microclimatic Effect |
|---|---|---|---|---|
|  |  |  |  |  |

Assign each row a stable Response ID. Record its evidence type (Measured, Simulated, Documented design, Documented use, Mechanism inference or Unknown), exact source ID and page/figure/section. Separately record whether evidence concerns the same object, a comparable building/type, a generic mechanism or an unknown relation.

For every claim, specify the outcome variable, comparator, operating/study conditions, verification status and limitations. Numerical values require a traceable source, units and scope. Leave numerical fields blank for unquantified effects; do not substitute zero. Distinguish air, surface, mean radiant and operative temperature. Source metadata verification is not claim verification.

The partner workbook version 1.2 uses matching IDs in Responses and Evidence. See [the evidence protocol](evidence-protocol.md). Climate charts use a centrally supplied 1991–2020 regional baseline; future projections and analogue scores are currently withheld pending validation.

### 6. Media

Provide only images that can be used legally.

For each image, include:

- filename
- caption
- photographer/source
- URL/publication
- license or permission status

### 7. References

Include academic, archival, fieldwork, or other credible references.

### 8. Contributor information

- Name(s)
- Institution
- Semester or project context, if applicable
- Contact, optional
